# Conversational Process Intelligence: Hybrid Architecture and LLM-Only Baseline

Code and experimental materials associated with the paper:

**From Event Logs to Conversational Process Intelligence: A Hybrid Architecture and Prototype for Natural Language-Based Process Analysis**

This repository contains the implementations used in the comparative evaluation of a hybrid Conversational Process Intelligence architecture and an LLM-only baseline. The hybrid approach combines deterministic process analytics with LLM-based natural-language interpretation, whereas the LLM-only baseline analyzes the raw event log directly without access to deterministic analytical functions.
